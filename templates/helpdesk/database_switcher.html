How Yearly Databases Work
{% for num, icon, col, text in steps %} {% endfor %}
1
Each year gets its own PostgreSQL database — e.g. beitdesk_2025, beitdesk_2026. Records stay clean, fast and separated by year.
2
At year start an administrator registers the new database here, runs the SQL setup below, and marks it as Current.
3
Any user can Switch to a previous year to view historical tickets and calls. The sidebar shows a year badge while viewing a past year.
4
Past year databases are for viewing only. New tickets should only be created in the current year.
