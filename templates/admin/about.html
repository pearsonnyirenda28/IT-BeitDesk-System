About BeitDesk

Municipality of Beitbridge — IT Help Desk & Support System

ℹ️System Overview

BeitDesk is the official IT Help Desk and Support Management System for the Municipality of Beitbridge. It provides a centralised platform for logging, tracking, and resolving IT support tickets raised by municipal staff, while also monitoring VoIP call activity for the IT department.

🏛️Organisation

OrganisationMunicipality of Beitbridge
DepartmentInformation Technology
SystemBeitDesk v1.0
FrameworkDjango 5.2 / Python 3.14
DatabasePostgreSQL 18
Established2007

✅System Capabilities

✔ Ticket creation, assignment, and tracking
✔ Priority and category management
✔ VoIP call logging with caller ID
✔ Live call board with auto-refresh
✔ Role-based access control (Admin / Staff / User)
✔ Immutable audit trail with full event history
✔ Agent workload monitoring
✔ Period-based reporting and analytics
✔ Caller directory and history
✔ Self-service profile and password management

🔐Access Control

Role Capabilities
Administrator Full system access, assign tickets, manage all users
IT Staff All tickets, take unassigned, change status, view own audit
User Own tickets only, own audit events, own profile
