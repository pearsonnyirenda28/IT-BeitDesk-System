How to Use BeitDesk

Step-by-step guide for administrators and IT staff

Jump to: Tickets VoIP Calls User Management Audit Trail Reports Roles & Permissions Groups VoIP LAN Setup

🎫 Ticket Management

Creating a Ticket

  1. Click New Ticket in the top bar or sidebar.
  2. Fill in the Title and Description — be specific about the issue.
  3. Select the Category (e.g. Network, Hardware, Software).
  4. Set the Priority: Low / Medium / High / Critical.
  5. Set the Source: how the issue was reported (Web, Phone, Walk-In, VoIP, Email).
  6. Enter the Requester details — name, email, phone, department.
  7. Click Create Ticket. The system assigns a unique ID (e.g. ND001001).
⚠️ Important: Once created, ticket fields cannot be edited. Ensure all details are correct before submitting. Only the status can be changed afterwards.

Managing Ticket Status

Status Meaning Who can set

Assigning Tickets

  • Administrators can assign any ticket to any IT staff member from the ticket detail page.
  • IT Staff can take any open, unassigned ticket by clicking Take This Ticket. The ticket automatically moves to In Progress.
  • Once assigned, only administrators can reassign the ticket to someone else.

📞 VoIP Call Tracking

ℹ️ Live call events require a PBX/Asterisk integration on the LAN. Manual call logging is always available regardless.

Logging a Call Manually

  1. Click Log Call in the top bar or VoIP → Log a Call in the sidebar.
  2. Enter the Caller Number (full number with country code, e.g. +263771234567).
  3. Enter the Caller Name if known.
  4. Set the Direction (Inbound / Outbound / Internal) and Status.
  5. Enter the Talk Duration in minutes (decimals allowed, e.g. 2.5 = 2m 30s).
  6. Add Notes summarising the call topic.
  7. Optionally tick Also create a ticket to log a support issue from the call.

Call Log & Caller Directory

  • The Call Log lists all recorded calls with filters for date, status, and direction.
  • The Caller Directory tracks known callers — name, company, total calls, last call, VIP/blocked flags.
  • From any call record, click Create Ticket to raise a linked support ticket pre-filled with caller details.

👥 User Management

Creating a New User

  1. Go to Analytics → Manage Users in the sidebar.
  2. Click Add User (superusers only).
  3. Fill in username, name, email, and a password of at least 8 characters.
  4. Tick Grant IT Staff access if this person should be an agent who can manage tickets.
  5. Click Create User.

Resetting a Password

  1. Go to Manage Users and click the gear icon next to the user.
  2. In the Reset Password panel, enter and confirm the new password.
  3. Click Reset Password. The user must use this new password on next login.

Deactivating a User

  • On the user's detail page, click Deactivate Account.
  • The user cannot log in, but all their ticket history and audit events are preserved.
  • Click Reactivate Account to restore access at any time.
  • IT Staff cannot deactivate or manage administrator accounts.

🛡️ Audit Trail

  • Every action in BeitDesk is recorded: logins, ticket creation, status changes, assignments, comments, call logs, and user changes.
  • Administrators can see all events across all users.
  • IT Staff can see only their own audit events.
  • Regular Users see only their own events on the dashboard — they cannot access the full audit trail page.
  • The audit trail records the user, action, timestamp, and IP address for every event.
  • Audit records cannot be edited or deleted through the application interface.

📊 Reports

  • Go to Analytics → Reports from the sidebar.
  • Use the period selector to view data for the last 7, 30, 90, or 365 days.
  • Reports show: total tickets created and resolved, average resolution time, breakdown by priority/category/source, and agent performance.
  • VoIP stats show total calls, completion rate, missed calls, and average call duration for the period.

👥 Groups (Django Permission Groups)

BeitDesk uses Django's built-in Groups system for additional permission granularity. Groups are managed from the Admin Panel under Authentication and Authorization → Groups.

Role Flags vs Groups

Role / Flag Set via Effect in BeitDesk
is_superuser Manage Users → Promote to Administrator Full access — all tickets, all users, full audit log, assign tickets
is_staff Manage Users → Grant Staff Role All tickets visible, can take/change status, own audit log
Neither Default for new users Own tickets only, own profile, own audit events on dashboard
Django Group Admin → Groups → assign to user Model-level permissions (add/change/delete on specific models)

Creating a Custom Group

  1. Go to /admin/ → Authentication and Authorization → Groups → Add Group.
  2. Name the group (e.g. Level 2 Support).
  3. In the Permissions panel, select the model permissions this group should have (e.g. helpdesk | ticket | Can view ticket).
  4. Click Save.
  5. To assign: open any user in /admin/auth/user/, scroll to Groups, and add them to the group.
ℹ️ For most deployments the is_staff and is_superuser flags (managed from BeitDesk's own Manage Users page) are sufficient. Use Django Groups only when you need fine-grained model permissions beyond the three built-in roles.

🔌 Configuring Live VoIP on LAN (Asterisk / FreePBX)

BeitDesk supports live call events from a PBX on your local network. When configured, calls appear on the Live Call Board automatically. Manual logging always works with or without a PBX connected.

Requirements

  • Asterisk 18+ or FreePBX 16+ on the same LAN as BeitDesk
  • AMI (Asterisk Manager Interface) enabled on the PBX
  • BeitDesk server reachable from the PBX on its port (default 8000)

Step 1 — Enable AMI on the PBX

Edit /etc/asterisk/manager.conf: 

[general]
enabled = yes
port = 5038
bindaddr = 0.0.0.0

[beitdesk]
secret = your_ami_password_here
read = call,cdr,agent
write = call
permit = 192.168.1.0/255.255.255.0   ; replace with your LAN subnet

Restart Asterisk: sudo systemctl restart asterisk

Step 2 — Update .env

ASTERISK_HOST=192.168.1.10       # PBX IP on your LAN
ASTERISK_PORT=5038               # AMI port (default 5038)
ASTERISK_USERNAME=beitdesk       # matches [beitdesk] in manager.conf
ASTERISK_PASSWORD=your_ami_password_here

Step 3 — Add VoIP Provider in BeitDesk Admin

  1. Go to /admin/ → Voip → Voip providers → Add.
  2. Set Name (e.g. Beitbridge PBX), Host to the PBX LAN IP, Port to 5060 (SIP), Protocol to SIP.
  3. Tick Is active and save.

Step 4 — Register Extensions

  1. Go to /admin/ → Voip → Extensions → Add.
  2. Enter the Extension number (e.g. 4001).
  3. Link to the User (IT staff member using that extension).
  4. Set Department and select the VoIP provider.
  5. Repeat for each IT staff extension.

Step 5 — Test

  1. Make a test call to a registered extension.
  2. Open VoIP → Live Board — the call should appear within seconds.
  3. If nothing appears, verify the PBX can reach BeitDesk on port 8000 and AMI credentials match.
⚠️ Firewall: Port 5038 must be open between BeitDesk and the PBX. On Windows: Windows Firewall inbound rule. On Linux: sudo ufw allow 5038.
✅ No PBX? Use VoIP → Log a Call manually. All other features including the call board work fully in manual mode.
